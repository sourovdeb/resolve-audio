01 / Open the app

  1. Extract the ZIP.
  2. Open the extracted folder.
  3. Double-click VoiceMacro.exe.
  4. Open your project in Resolve.
  5. Duplicate a timeline for testing.
  6. Choose your voice track.

Windows 10/11; .NET Framework 4.8.
No Python, account, or API key.

KNOB 01

Depth

Adds body around 140 Hz.
Cuts mud around 320 Hz.

KNOB 02

Presence

Adds definition around 3.2 kHz.
Raises the treble shelf.

KNOB 03

Control

Combines compression and makeup gain.
Recording level affects compression.

03 / Connect seven fields

Choose Setup in Voice Macro.
Keep Fairlight's windows visible.
Keep them on the same track.

  1. Select the first listed field.
  2. Click Capture field.
  3. The app hides for four seconds.
  4. Hover over that field's number.
  5. Don't click or move.
  6. The app captures your pointer position.
  7. Repeat for the remaining fields.
  8. Click Verify mappings.
  9. Check the reported numbers.
  10. Click Done.

04 / Turn and listen

  1. Start with Depth 35.
  2. Set Presence to 25.
  3. Set Control to 30.
  4. Click Apply.
  5. Leave the mouse and keyboard alone.
  6. The controller checks applied values.
  7. Play your speech in Resolve.

Enable Apply on release after verification.
Drag a knob up or down.
Release it to apply changes.
Arrow keys also adjust knobs.
Hold Shift for smaller mouse changes.

Escape stops the operation.
Earlier writes may already exist.
Restore recalls the previous batch.
Knobs remain proposed settings after restoring.

If the voice booms

Reduce Depth.
Check microphone distance and plosives.

If sibilance increases

Reduce Presence.
Consider Fairlight's De-Esser.

If breathing sounds exaggerated

Reduce Control.
Compression can expose room noise.

If output clips

Reduce input gain or makeup.
Check Resolve's output meter.

Compare versions at matched loudness.
Louder playback can influence preference.
These knobs don't lower vocal pitch.
Microphone equivalence isn't guaranteed.

05 / Save your sound

Save knob positions

  1. Click Save in Voice Macro.
  2. Name the JSON preset.
  3. Use Load to recall it.
  4. Click Apply after loading.

JSON contains three knob positions.
It doesn't contain Fairlight's baseline.

Save within Resolve

  1. Open Fairlight → Presets Library.
  2. Select your voice track.
  3. Choose Global Track Presets.
  4. Click Save New.
  5. Name and save your preset.

Global presets include other track settings.
Separate EQ/Dynamics presets are alternatives.
