Open from Workspace

  1. Extract the whole ZIP.
  2. Close Resolve and VoiceMacro.
  3. Run install\Install-VoiceMacro.cmd.
  4. Restart Resolve Studio.
  5. Choose Workspace → Workflow Integrations → VoiceMacro.

Windows may request administrator approval for the menu entry. The alternative menu is Workspace → Scripts → VoiceMacro. You can also run VoiceMacro.exe from the extracted ZIP.

The app installs in %LOCALAPPDATA%\VoiceMacro\App. The menu launcher installs in %PROGRAMDATA%\Blackmagic Design\DaVinci Resolve\Support\Workflow Integration Plugins\com.sourovdeb.voicemacro.

The Windows build compiled. Resolve menu loading and field input await testing on Windows.

Match a recording

  1. Install Python 3 and FFmpeg with install\Install-Matcher-Tools.cmd if needed. Reopen Resolve afterward.
  2. Open Match WAV. Choose the WAV you want to improve.
  3. Choose a reference WAV or profile. The ZIP supplied with a reference profile selects it for you.
  4. Choose an action from the table.
ActionResult
Match voiceMatches tone and level. Uses compression only when the target shows more level variation.
Match EQMatches tone. Aims to preserve the target's measured loudness within the peak limit.
Match levelChanges gain alone. Choose reference loudness, −16 LUFS, or the current level.
Use with knobsLoads measured EQ and compressor settings. Turn the dials, then apply them to the mapped Fairlight track.

The first three actions create a new 24-bit WAV. Import it into Resolve and align it with the original. Existing files stay intact. The app uses your dial positions for file matching.

The YouTube starting point is −16 LUFS with a −2 dBTP ceiling. The matcher may leave the WAV quieter to preserve headroom. Check the final mix after adding music or editing gain.

For command-line use, open a terminal in the extracted folder. Choose a new output name.

py -3 matcher\match_voice.py match "target.wav" --reference "reference.wav" --output "matched.wav" --loudness youtube

Connect the Fairlight knobs

  1. Open the target track's EQ and Dynamics in the Fairlight Mixer.
  2. Use Recipe to set the band shapes, frequencies, and processor switches.
  3. In Setup, select a field. Click Capture field. Hover over that number for four seconds.
  4. Repeat for each number you want VoiceMacro to control.
  5. Select a field in each group. Click Verify group. Check the readback against the track.
  6. Click Done. Turn a dial and choose Apply.
GroupMap the numeric readouts
EQBand 2, 3, 4, and 5 gain.
DynamicsCompressor threshold, ratio, and makeup gain.
LevelTrack fader dB. Optional for Copy and Paste.

In WAV match mode, Depth scales bass and low mids. Presence scales definition and air. Control scales the proposed compression. Confirm the mapped track before applying.

Use Track profiles to apply EQ or Dynamics on its own. Close overlapping windows. If a field cannot be read, use the numbers in Recipe.

Apply on release applies changes when you release a dial. Escape stops input. Restore recalls the preceding batch if the mapping still matches.

Copy a track's sound

  1. Verify the source track's mapped groups.
  2. Choose Track profiles. Pick Voice, EQ gains, Dynamics, or Mixer fader. Choose Copy.
  3. Map and verify the destination. Keep its windows open.
  4. Choose the same group and Paste.

Voice copies EQ gains and compressor controls together. Use the same Recipe on both tracks. To copy an entire EQ or Dynamics module, use that graph's right-click Copy and Paste in Resolve.

The Workspace menu opens the app. The Fairlight panels list settings you create and save in Resolve.

Resolve's clip tools

Right-click the reference clip. Look for Clip Operations → EQ Matcher or Level Matcher. Capture the profile. Then right-click the target clip and apply it. Use the clip EQ option to affect just that clip. Menu wording can vary by build.

Resolve's Dialogue Matcher lives under AI Tools. VoiceMacro's WAV matcher uses measured frequency, level, and dynamics. Use a speech clip without music for the reference.
