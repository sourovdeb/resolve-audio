VoiceMacro

Match your voice to the supplied Zoom H1n reference.

  1. Extract the ZIP.
  2. Run VoiceMacro.exe.
  3. Choose the voice WAV.
  4. Wait for the new -VoiceMacro.wav.
  5. Import it into Resolve and listen.

Install Python 3 and FFmpeg if requested. The package includes install\Install-Matcher-Tools.cmd for Windows Package Manager.

Console option

Run Run-VoiceMacro.cmd. It can find a WAV from an open Resolve timeline. For a file, run py -3 voice_macro_console.py --input "C:\recordings\voice.wav".

The numerical reference and its instructions live in Zoom-H1n-Voice-Reference.json. You can change the dials afterward. See README.md for the optional controls.
