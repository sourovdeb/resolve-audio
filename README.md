# VoiceMacro for DaVinci Resolve

Voice matching for Resolve Studio 21 on Windows.

1. Download and extract the project ZIP.
2. Run `implementation/VoiceMacro.exe`.
3. Choose a target WAV. Matching starts with the bundled reference.

For a console flow, run `implementation/Run-VoiceMacro.cmd`.
